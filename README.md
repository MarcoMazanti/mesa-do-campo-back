# Mesa do Campo
- - -
## Versionamento (Branchs)
### • prod
Esta branch armazena apenas o produto final, após as passagens de testes.
### • homolog
Esta branch será realizada testes massivos para verificar o funcionamento na prática do banco de dados.
### • dev
É onde fica onde será feito a junção de todas as branches features, assim centrealizando o desenvolvimento.
### • feature
É o ambiente pessoal de desenvolvimento dos desenvolvedores, onde ocorrerá a construção de uma única funcionalidade.

### Ordem de Merge:
feature → dev → homolog → prod
